# RFID2 holder

3D-printable case for [M5Stack Unit RFID2](https://docs.m5stack.com/en/unit/rfid2).

## Files

- `rfid2_a1mini_all.3mf`: all parts laid out for Bambu Lab A1 mini
  - `RFID2_plate_std` / `RFID2_lid_std`
  - `RFID2_plate_flat` / `RFID2_lid_flat`

Non-manifold edges and zero-volume faces in the original export have been repaired. The geometry itself is unchanged.

## Notes

- Clearance between lid and plate: 0.15 mm
- The following features are thinner than one layer and may not be printed as designed:
  - Snap tab tip: 0.02 mm
  - Lip: 0.12 mm
  - Groove step: 0.01 mm
